🇮🇳 Indian Economic Analytics & Forecasting

Data Analytics | Machine Learning | Economic Forecasting

An end-to-end Data Analytics and Machine Learning project focused on analyzing and forecasting India's Union Budget trends from 1997 to 2026 using Python and Scikit-Learn.

---

📌 Project Overview

The Indian Economic Analytics & Forecasting project explores historical Indian Union Budget data to understand government revenue and expenditure patterns and apply machine learning techniques for forecasting.

The project uses data analysis, visualization, and predictive modeling to identify economic trends and support data-driven insights into India's budget.

🎯 Project Objectives

- Analyze historical Indian Union Budget data.
- Understand government receipts and expenditure patterns.
- Identify year-wise budget trends and variations.
- Perform Exploratory Data Analysis (EDA).
- Apply Machine Learning techniques for economic forecasting.
- Visualize historical data and forecast trends.
- Generate meaningful insights from economic datasets.

📊 Dataset Description

The project repository contains the following datasets:

1. India Budget Master Data (CSV)

- Consolidated Indian budget dataset.
- Used for data analysis and forecasting.

2. Expenditure.xlsx

- Government expenditure data.
- Used to explore spending patterns.

3. Receipts.xlsx

- Government receipts data.
- Used to analyze revenue trends.

Historical Coverage: 1997–2028 (as described by the project).

⚙️ Project Workflow

1. Data Collection – Load budget datasets.
2. Data Preprocessing – Prepare and clean data.
3. Exploratory Data Analysis – Explore economic trends.
4. Data Visualization – Create graphical representations.
5. Feature Preparation – Prepare data for forecasting.
6. Machine Learning – Apply predictive modeling using Scikit-Learn.
7. Forecasting – Analyze and estimate future budget trends.
8. Insights – Interpret the analytical findings.

🚀 Installation & Setup

Step 1: Clone the repository

git clone https://github.com/Ankitrao15/INDIAN-ECONOMIC-ANALYTICS-FORECASTING.git

Step 2: Navigate to the project directory

cd INDIAN-ECONOMIC-ANALYTICS-FORECASTING

Step 3: Install dependencies

pip install pandas numpy matplotlib seaborn scikit-learn openpyxl jupyter

Step 4: Launch Jupyter Notebook

jupyter notebook

Step 5: Open the notebook

Open "main checkpoint.ipynb" and run the cells sequentially.
